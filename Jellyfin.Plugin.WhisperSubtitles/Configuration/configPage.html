Zero lets this machine decide, which is one item at a time. A number above one per processor is refused rather than quietly reduced, and the run keeps the default until you change it.
Zero lets this machine decide, which is half the processors it reports, so the server keeps the rest for playback. A number above one per processor is refused rather than quietly reduced. These two limits are not checked against each other: raising both to their ceilings asks for the whole machine several times over.
Neither number reaches a transcription yet. Both are stored and checked here, and what would carry them to a backend is the run this plugin does not perform, so changing them today changes what the file says and nothing a server does.
