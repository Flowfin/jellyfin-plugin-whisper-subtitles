Zero lets this machine decide, which is one item at a time. A number above one per processor is refused rather than quietly reduced, and the run keeps the default until you change it.
Zero lets this machine decide, which is half the processors it reports, so the server keeps the rest for playback. A number above one per processor is refused rather than quietly reduced. These two limits are not checked against each other: raising both to their ceilings asks for the whole machine several times over.
Both numbers are read by the dry run that says what a run would cost, so changing them changes the cost it reports. Neither reaches a transcription, because what would carry them to a backend is the run this plugin does not perform, and nothing on this page offers the dry run yet either.
Zero lets this plugin decide, which is three. An item that fails this many times is quarantined and later runs skip it, so a broken file is not paid for every night. Runs you stop yourself never count. A failure nothing about tomorrow changes, such as an item with no audio, sets the item aside on the first attempt whatever this number says.
