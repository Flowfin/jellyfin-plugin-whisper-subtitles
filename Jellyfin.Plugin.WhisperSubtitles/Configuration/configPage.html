What this plugin wrote

The subtitles this plugin published are matched against its own record of what it wrote and never against a file name, so a subtitle a person made is never on this list. Listing removes nothing. Removing takes only the files listed as unchanged, and reads each one again at the moment of deletion, so a file edited since it was written is kept: an edited transcription is somebody's work.
