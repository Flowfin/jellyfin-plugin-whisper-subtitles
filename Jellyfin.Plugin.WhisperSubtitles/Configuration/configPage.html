The base URL of an endpoint speaking the OpenAI audio transcription request shape, starting with https:// or http://. A URL that is not one is refused when the configuration is loaded, and no endpoint is named instead.
Sent in one request header and nowhere else. Leave it empty for an endpoint that wants none.
A name the endpoint serves. Which names it serves is the endpoint's business, and this plugin never lists them.
With this backend the extracted audio of every item a run selects leaves this server, whole, as the body of one request per item. It goes to the host in the URL above, and to nothing else. What that host does with the audio after it arrives, whether it keeps it, logs it, or uses it for anything else, is something this plugin cannot know and cannot ask. If you are answerable to somebody else for that audio, you are answerable for this setting.

Zero lets this machine decide, which is half the processors it reports, so the server keeps the rest for playback. A number above one per processor is refused rather than quietly reduced. These two limits are not checked against each other: raising both to their ceilings asks for the whole machine several times over.
Both numbers are read by the dry run that says what a run would cost, so changing them changes the cost it reports. Neither reaches a transcription, because what would carry them to a backend is the run this plugin does not perform, and nothing on this page offers the dry run yet either.
